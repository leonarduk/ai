## 🎯 What I'm Building

### MCP Server Suite
A collection of 7 production-ready Model Context Protocol servers that enable LLMs to interact with external systems.

**What it does:** Provides LLMs with structured access to GitHub, filesystems, git operations, email, web search, and more.

**What I learned:** Rate limiting strategies, API error handling, security patterns for file access, async Python at scale.

**Status:** Production-ready, actively maintained

📂 [View Project](./projects/01-mcp-server-suite/) | [Server Code](./projects/01-mcp-server-suite/servers/)

**Tech stack:** Python, AsyncIO, MCP Protocol, REST APIs, GitHub API, SMTP
